# google-office

Use the `goog` CLI for Google Drive, Docs, Sheets, and GoogleMail through local OAuth.
The CLI owns installation, OAuth setup, account tokens, scopes, and multi-account selection.

For install and first-time setup, see the [`goog-cli` README](https://github.com/SainyTK/goog-cli#installation) and [`goog auth` setup guide](https://github.com/SainyTK/goog-cli#oauth-setup).
